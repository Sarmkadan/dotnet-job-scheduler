# CacheServiceValidation

This document describes the validation helpers for the `CacheService` class. See [CacheService.md](./CacheService.md) for the main cache service documentation.

## Validation Methods

The `CacheServiceValidation` static class provides 13 public extension methods for validating cache-related objects.

| Method Signature | What is Validated | What is Thrown/Returned | Example |
|------------------|-------------------|-------------------------|---------|
| `public static IReadOnlyList<string> Validate(this CacheService? value)` | `CacheService` instance for common issues (currently validates only that the instance is not null) | Returns a list of validation problems (empty if valid). Throws `ArgumentNullException` if `value` is null. | ```csharp\nvar cacheService = new CacheService(...);\nvar problems = cacheService.Validate(); // Returns empty list\n``` |
| `public static bool IsValid(this CacheService? value)` | Whether a `CacheService` instance is valid (not null and passes validation) | Returns `true` if valid, `false` otherwise. Does not throw exceptions. | ```csharp\nvar cacheService = new CacheService(...);\nbool isValid = cacheService.IsValid(); // Returns true\n``` |
| `public static void EnsureValid(this CacheService? value)` | Ensures a `CacheService` instance is valid | Throws `ArgumentNullException` if `value` is null. Throws `ArgumentException` with validation problems if any exist. Returns nothing if valid. | ```csharp\nvar cacheService = new CacheService(...);\ncacheService.EnsureValid(); // Does nothing if valid\n``` |
| `public static IReadOnlyList<string> ValidateKey(string? key)` | Cache key string for validity (null/empty, length > 1024, whitespace, non-ASCII) | Returns a list of validation problems (empty if valid). Throws `ArgumentNullException` if `key` is null. Throws `ArgumentException` if `key` is empty. | ```csharp\nstring key = \"my-cache-key\";\nvar problems = CacheServiceValidation.ValidateKey(key); // Returns empty list\n``` |
| `public static bool IsValidKey(string? key)` | Whether a cache key is valid | Returns `true` if the key is valid, `false` otherwise. Does not throw exceptions. | ```csharp\nbool isValid = CacheServiceValidation.IsValidKey(\"my-cache-key\"); // Returns true\n``` |
| `public static void EnsureValidKey(string? key)` | Ensures a cache key is valid | Throws `ArgumentNullException` if `key` is null. Throws `ArgumentException` if `key` is empty or has validation problems. Returns nothing if valid. | ```csharp\nCacheServiceValidation.EnsureValidKey(\"my-cache-key\"); // Does nothing if valid\n``` |
| `public static IReadOnlyList<string> ValidateKeyPattern(string? keyPattern)` | Cache key pattern string for validity (null/empty, length > 1024, missing wildcards) | Returns a list of validation problems (empty if valid). Throws `ArgumentNullException` if `keyPattern` is null. Throws `ArgumentException` if `keyPattern` is empty. | ```csharp\nstring pattern = \"user:*\";\nvar problems = CacheServiceValidation.ValidateKeyPattern(pattern); // Returns empty list\n``` |
| `public static bool IsValidKeyPattern(string? keyPattern)` | Whether a cache key pattern is valid | Returns `true` if the pattern is valid, `false` otherwise. Does not throw exceptions. | ```csharp\nbool isValid = CacheServiceValidation.IsValidKeyPattern(\"user:*\"); // Returns true\n``` |
| `public static void EnsureValidKeyPattern(string? keyPattern)` | Ensures a cache key pattern is valid | Throws `ArgumentNullException` if `keyPattern` is null. Throws `ArgumentException` if `keyPattern` is empty or has validation problems. Returns nothing if valid. | ```csharp\nCacheServiceValidation.EnsureValidKeyPattern(\"user:*\"); // Does nothing if valid\n``` |
| `public static IReadOnlyList<string> Validate(this CacheStatistics? statistics)` | `CacheStatistics` instance for validity (negative TotalKeys, default Timestamp, non-Utc Timestamp, future Timestamp) | Returns a list of validation problems (empty if valid). Throws `ArgumentNullException` if `statistics` is null. | ```csharp\nvar stats = new CacheStatistics { TotalKeys = 10, Timestamp = DateTime.UtcNow };\nvar problems = stats.Validate(); // Returns empty list\n``` |
| `public static bool IsValid(this CacheStatistics? statistics)` | Whether `CacheStatistics` is valid | Returns `true` if the statistics are valid, `false` otherwise. Does not throw exceptions. | ```csharp\nvar stats = new CacheStatistics { TotalKeys = 10, Timestamp = DateTime.UtcNow };\nbool isValid = stats.IsValid(); // Returns true\n``` |
| `public static void EnsureValid(this CacheStatistics? statistics)` | Ensures `CacheStatistics` is valid | Throws `ArgumentNullException` if `statistics` is null. Throws `ArgumentException` with validation problems if any exist. Returns nothing if valid. | ```csharp\nvar stats = new CacheStatistics { TotalKeys = 10, Timestamp = DateTime.UtcNow };\nstats.EnsureValid(); // Does nothing if valid\n``` |
